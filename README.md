A couple of school projects, each self contained in content. Constructed using Jupyter Notebook.
This was a modeling and simulation class, and therefore have a lot of physics-based features.

The class emphasized importance of the design process, such as understanding the model before starting, 
and identifying what objects interact with each other before even touching a keyboard.

Note: due to Github's .ipynb translation, some textboxes are missing, but none of the source code is
missing. Only certain reflection points.
